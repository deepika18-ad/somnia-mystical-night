## Suggested demo flow
1. Open home page and explain the project is non-diagnostic.
2. Register a synthetic test account and show the dashboard.
3. Explain the ML pipeline and show the actual evaluation metrics generated by `train_model.py`.
4. Submit an assessment after training has completed.
5. Show saved history.
6. Explain that a second account cannot access the first account's assessment through backend ownership checks.
7. Discuss dataset limitations, class imbalance, model metrics and future scope.

## Important reporting rule
Never claim the published IEEE paper's accuracy as the result of this implementation. Report only metrics produced by your own held-out evaluation.
